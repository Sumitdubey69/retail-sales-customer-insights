# Retail Sales & Customer Insights

## Project Overview

This project analyzes retail sales data to identify sales trends, product performance, customer spending patterns, and customer demographics.

## Objectives

- Identify the best-performing product categories
- Analyze monthly sales trends
- Compare sales by gender
- Analyze sales by age group
- Identify high-spending customers
- Generate useful business insights

## Tools & Technologies

- Python
- Pandas
- Matplotlib
- Google Colab
- GitHub

## Dataset

The dataset contains retail transaction information, including:

- Transaction ID
- Date
- Customer ID
- Gender
- Age
- Product Category
- Quantity
- Price per Unit
- Total Amount

## Analysis Performed

### 1. Product Category Analysis

Analyzed total sales for each product category to identify the best-performing category.

### 2. Monthly Sales Analysis

Analyzed sales by month to understand sales trends over time.

### 3. Gender-wise Sales Analysis

Compared total sales generated by different genders.

### 4. Age Group Analysis

Grouped customers into age categories and analyzed their sales contribution.

### 5. Customer Spending Analysis

Identified customers with the highest total spending.

## Key Business Insights

- Product category analysis helps identify popular products.
- Monthly sales analysis helps understand sales trends.
- Gender-wise analysis supports customer targeting.
- Age-group analysis helps businesses understand customer segments.
- Customer spending analysis helps identify valuable customers.

## Conclusion

This project demonstrates how Python, Pandas, and Matplotlib can be used to analyze retail data and convert raw transaction data into meaningful business insights.
